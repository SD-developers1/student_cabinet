# 🎓 Student Cabinet

**Student Cabinet** — Flutter texnologiyasi yordamida ishlab chiqilayotgan talabalar uchun elektron shaxsiy kabinet ilovasi.

Ilova talabalar uchun o‘quv jarayoniga oid ma'lumotlarni qulay interfeys orqali ko‘rish va boshqarish imkoniyatini yaratishga mo‘ljallangan.

## 📱 Ilova haqida

Student Cabinet loyihasi zamonaviy, sodda va foydalanishga qulay mobil ilova yaratish maqsadida ishlab chiqilgan.

Ilova Flutter frameworki asosida Dart dasturlash tilida yozilgan.

## ✨ Asosiy imkoniyatlar

- 🔐 **Login** — tizimga kirish oynasi.
- 🏠 **Home** — bosh sahifa.
- 📚 **Subjects** — fanlar bo‘limi.
- 📊 **Grades** — talabalar baholarini ko‘rish bo‘limi.
- 👤 **Profile** — foydalanuvchi profili.
- 🌙 **Dark Mode** — tungi rejimni yoqish va o‘chirish.
- 💾 **Local Storage** — foydalanuvchi sozlamalarini saqlash.

## ⚙️ Loyihani ishga tushirish

Loyihani kompyuteringizga yuklab oling:

```bash
git clone https://github.com/SD-developers1/student_cabinet.git
```

Loyiha papkasiga kiring:

```bash
cd student_cabinet
```

Kerakli kutubxonalarni yuklang:

```bash
flutter pub get
```

Ilovani ishga tushiring:

```bash
flutter run
```
